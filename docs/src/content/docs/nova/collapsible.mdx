# Collapsible

## Usage

Add the theme to your CSS:

```css
@import "tailwindcss";
@import "@danielfrg/solid-ui-nova/theme.css";
```

Import and use the Collapsible components:

```tsx
import { Collapsible, CollapsibleTrigger, CollapsibleContent } from "@danielfrg/solid-ui-nova/collapsible"
<Collapsible>
  <CollapsibleTrigger class="inline-flex h-8 items-center justify-center rounded-md px-3 text-sm font-medium hover:bg-accent">
    Toggle
  </CollapsibleTrigger>
  <CollapsibleContent>Hidden content revealed on toggle.</CollapsibleContent>
</Collapsible>
```

## Parts

| Component            | Description                          |
| -------------------- | ------------------------------------ |
| `Collapsible`        | Root container with open/close state |
| `CollapsibleTrigger` | Button that toggles visibility       |
| `CollapsibleContent` | Content that expands/collapses       |
