# Theme: Nova

A collection of styled components built on top of `@danielfrg/solid-ui` using [shadcn's Nova styles](https://ui.shadcn.com) and Tailwind v4.

Demos copy the shadcn "create" examples.

## Installation

```bash
npm install @danielfrg/solid-ui-nova
```

Add the theme to your CSS:

```css
@import "tailwindcss";
@import "@danielfrg/solid-ui-nova/theme.css";
```
