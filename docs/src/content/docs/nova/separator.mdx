# Separator

## Usage

Add the theme to your CSS:

```css
@import "tailwindcss";
@import "@danielfrg/solid-ui-nova/theme.css";
```

Import and use the `Separator` component:

```tsx
import { Separator } from "@danielfrg/solid-ui-nova/separator";

<Separator />
<Separator orientation="vertical" />
```
