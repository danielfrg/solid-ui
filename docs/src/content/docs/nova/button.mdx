# Button

## Usage

Add the theme to your CSS:

```css
@import "tailwindcss";
@import "@danielfrg/solid-ui-nova/theme.css";
```

Import and use the `Button` component:

```tsx
import { Button } from "@danielfrg/solid-ui-nova/button"

;<Button variant="outline" size="sm">
  Click me
</Button>
```
