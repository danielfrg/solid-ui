# Progress

## Usage

Add the theme to your CSS:

```css
@import "tailwindcss";
@import "@danielfrg/solid-ui-nova/theme.css";
```

Import and use the Progress components:

```tsx
import { Progress, ProgressLabel, ProgressValue } from "@danielfrg/solid-ui-nova/progress"
;<Progress value={33}>
  <div class="flex justify-between mb-2">
    <ProgressLabel>Loading...</ProgressLabel>
    <ProgressValue />
  </div>
</Progress>
```

## Parts

| Component            | Description                       |
| -------------------- | --------------------------------- |
| `Progress`           | Root with built-in track and fill |
| `ProgressLabel`      | Text label for the progress bar   |
| `ProgressValueLabel` | Displays the current percentage   |
| `ProgressValue`      | Alias for `ProgressValueLabel`    |
