# Switch

## Usage

Add the theme to your CSS:

```css
@import "tailwindcss";
@import "@danielfrg/ui/theme.css";
```

Import and use the Switch components:

```tsx
import { Switch, SwitchLabel } from "@danielfrg/ui/switch"
;<Switch defaultChecked>
  <SwitchLabel>Airplane Mode</SwitchLabel>
</Switch>
```
