# Toggle

## Usage

Add the theme to your CSS:

```css
@import "tailwindcss";
@import "@danielfrg/ui/theme.css";
```

Import and use the `Toggle` component:

```tsx
import { Toggle } from "@danielfrg/ui/toggle"
import { Bold } from "lucide-solid"
;<Toggle variant="outline" aria-label="Toggle bold">
  <Bold />
</Toggle>
```

## Variants

| Variant   | Description            |
| --------- | ---------------------- |
| `default` | Transparent background |
