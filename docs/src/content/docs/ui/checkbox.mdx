# Checkbox

## Usage

Add the theme to your CSS:

```css
@import "tailwindcss";
@import "@danielfrg/solid-ui/theme.css";
```

Import and use the Checkbox components:

```tsx
import { Checkbox, CheckboxLabel } from "@danielfrg/solid-ui/checkbox"
<Checkbox defaultChecked>
  <CheckboxLabel>Accept terms and conditions</CheckboxLabel>
</Checkbox>
```
