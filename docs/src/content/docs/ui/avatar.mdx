# Avatar

## Usage

Add the theme to your CSS:

```css
@import "tailwindcss";
@import "@danielfrg/solid-ui/theme.css";
```

Import and use the Avatar components:

```tsx
import { Avatar, AvatarImage, AvatarFallback } from "@danielfrg/solid-ui/avatar"
<Avatar>
  <AvatarImage src="/avatar.png" />
  <AvatarFallback>CN</AvatarFallback>
</Avatar>
```

## Parts

| Component        | Description                                    |
| ---------------- | ---------------------------------------------- |
| `Avatar`         | Root container (rounded, overflow hidden)      |
| `AvatarImage`    | The user image                                 |
| `AvatarFallback` | Displayed when image is loading or unavailable |
