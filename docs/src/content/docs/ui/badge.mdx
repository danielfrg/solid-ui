# Badge

## Usage

Add the theme to your CSS:

```css
@import "tailwindcss";
@import "@danielfrg/solid-ui/theme.css";
```

Import and use the `Badge` component:

```tsx
import { Badge } from "@danielfrg/solid-ui/badge"

<Badge variant="outline">Badge</Badge>
```
