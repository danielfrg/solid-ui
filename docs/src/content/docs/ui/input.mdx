# Input

## Usage

Add the theme to your CSS:

```css
@import "tailwindcss";
@import "@danielfrg/ui/theme.css";
```

Import and use the Input components:

```tsx
import { Input, InputField, InputLabel } from "@danielfrg/ui/input"
;<Input>
  <InputLabel>Email</InputLabel>
  <InputField type="email" placeholder="you@example.com" />
</Input>
```

## Parts

| Component           | Description                                          |
| ------------------- | ---------------------------------------------------- |
| `Input`             | Root container (form control context provider)       |
| `InputField`        | The `<input>` element with shadcn styling            |
| `InputTextArea`     | The `<textarea>` element with shadcn styling         |
| `InputLabel`        | Accessible label linked to the field                 |
| `InputDescription`  | Helper text below the input                          |
| `InputErrorMessage` | Error message shown when `validationState="invalid"` |
