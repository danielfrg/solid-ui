# Slider

## Usage

Add the theme to your CSS:

```css
@import "tailwindcss";
@import "@danielfrg/solid-ui/theme.css";
```

Import and use the Slider components:

```tsx
import { Slider, SliderLabel, SliderValueLabel } from "@danielfrg/solid-ui/slider"
;<Slider defaultValue={[50]}>
  <div class="flex justify-between mb-3">
    <SliderLabel>Volume</SliderLabel>
    <SliderValueLabel />
  </div>
</Slider>
```

| Component          | Description                               |
| ------------------ | ----------------------------------------- |

| `SliderLabel`      | Text label for the slider                 |
| `SliderValueLabel` | Displays the current value                |
