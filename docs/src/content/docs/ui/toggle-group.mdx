# Toggle Group

## Usage

Add the theme to your CSS:

```css
@import "tailwindcss";
@import "@danielfrg/ui/theme.css";
```

Import and use the ToggleGroup components:

```tsx
import { ToggleGroup, ToggleGroupItem } from "@danielfrg/ui/toggle-group"
import { AlignLeft, AlignCenter, AlignRight } from "lucide-solid"
;<ToggleGroup defaultValue="center">
  <ToggleGroupItem value="left" aria-label="Align left">
    <AlignLeft />
  </ToggleGroupItem>
  <ToggleGroupItem value="center" aria-label="Align center">
    <AlignCenter />
  </ToggleGroupItem>
  <ToggleGroupItem value="right" aria-label="Align right">
    <AlignRight />
  </ToggleGroupItem>
</ToggleGroup>
```

## Variants

| Variant   | Description            |
| --------- | ---------------------- |
| `default` | Transparent background |
| `outline` | Bordered with shadow   |

## Sizes

| Size      | Description         |
| --------- | ------------------- |
| `default` | Standard size (h-9) |
| `sm`      | Small (h-8)         |
| `lg`      | Large (h-10)        |

## Parts

| Component         | Description                                               |
| ----------------- | --------------------------------------------------------- |
| `ToggleGroup`     | Root container (passes variant/size to items via context) |
| `ToggleGroupItem` | Individual toggle button                                  |
