# Progress

## Usage

Add the theme to your CSS:

```css
@import "tailwindcss";
@import "@danielfrg/ui/theme.css";
```

Import and use the Progress components:

```tsx
import { Progress, ProgressLabel, ProgressValueLabel } from "@danielfrg/ui/progress"
;<Progress value={33}>
  <div class="flex justify-between mb-2">
    <ProgressLabel>Loading...</ProgressLabel>
    <ProgressValueLabel />
  </div>
</Progress>
```

| Component            | Description                       |
