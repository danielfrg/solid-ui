# Context Menu

## Usage

Add the theme to your CSS:

```css
@import "tailwindcss";
@import "@danielfrg/solid-ui/theme.css";
```

Import and use the Context Menu components:

```tsx
import { ContextMenu, ContextMenuTrigger, ContextMenuContent, ContextMenuItem } from "@danielfrg/solid-ui/context-menu"
<ContextMenu>
  <ContextMenuTrigger>Right click here</ContextMenuTrigger>
  <ContextMenuContent>
    <ContextMenuItem>Back</ContextMenuItem>
    <ContextMenuItem>Forward</ContextMenuItem>
    <ContextMenuItem>Reload</ContextMenuItem>
  </ContextMenuContent>
</ContextMenu>
```

## Parts

| Component                 | Description                                       |
| ------------------------- | ------------------------------------------------- |
| `ContextMenu`             | Root container (manages open state)               |
| `ContextMenuTrigger`      | Area that responds to right-click / long-press    |
| `ContextMenuContent`      | The popup panel (includes Portal)                 |
| `ContextMenuItem`         | A menu item                                       |
| `ContextMenuCheckboxItem` | A toggleable checkbox menu item                   |
| `ContextMenuRadioGroup`   | Groups radio items                                |
| `ContextMenuRadioItem`    | A radio menu item                                 |
| `ContextMenuGroup`        | Groups related items                              |
| `ContextMenuLabel`        | A non-interactive label for a group               |
| `ContextMenuSeparator`    | A visual separator between items                  |
| `ContextMenuShortcut`     | Displays a keyboard shortcut hint                 |
| `ContextMenuSub`          | Root for a submenu                                |
| `ContextMenuSubTrigger`   | Item that opens a submenu (includes chevron icon) |
| `ContextMenuSubContent`   | The submenu popup panel                           |
