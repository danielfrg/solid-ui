# Dialog

## Usage

Add the theme to your CSS:

```css
@import "tailwindcss";
@import "@danielfrg/solid-ui/theme.css";
```

Import and use the Dialog components:

```tsx
import {
  Dialog,
  DialogTrigger,
  DialogContent,
  DialogHeader,
  DialogFooter,
  DialogTitle,
  DialogDescription,
} from "@danielfrg/solid-ui/dialog"
<Dialog>
  <DialogTrigger>Open</DialogTrigger>
  <DialogContent>
    <DialogHeader>
      <DialogTitle>Edit profile</DialogTitle>
      <DialogDescription>Make changes to your profile here.</DialogDescription>
    </DialogHeader>
    <DialogFooter>
      <button>Save changes</button>
    </DialogFooter>
  </DialogContent>
</Dialog>
```

## Parts

| Component           | Description                                              |
| ------------------- | -------------------------------------------------------- |
| `Dialog`            | Root container (manages open state)                      |
| `DialogTrigger`     | Button that opens the dialog                             |
| `DialogContent`     | The modal panel (includes Portal, Overlay, close button) |
| `DialogHeader`      | Layout wrapper for title and description                 |
| `DialogFooter`      | Layout wrapper for action buttons                        |
| `DialogTitle`       | Accessible title                                         |
| `DialogDescription` | Accessible description                                   |
| `DialogClose`       | Button that closes the dialog                            |
| `DialogOverlay`     | Backdrop overlay (included automatically in Content)     |
