# Alert

## Usage

Add the theme to your CSS:

```css
@import "tailwindcss";
@import "@danielfrg/solid-ui/theme.css";
```

Import and use the `Alert` component:

```tsx
import { Alert, AlertTitle, AlertDescription } from "@danielfrg/solid-ui/alert"
import { Terminal } from "lucide-solid"
;<Alert>
  <Terminal />
  <AlertTitle>Heads up!</AlertTitle>
  <AlertDescription>You can add components to your app using the cli.</AlertDescription>
</Alert>
```

## Variants

| Variant       | Description                            |
| ------------- | -------------------------------------- |
| `default`     | Standard alert with card background    |
| `destructive` | Error or warning with destructive tone |

## Parts

| Component          | Description                        |
| ------------------ | ---------------------------------- |
| `Alert`            | Root container with `role="alert"` |
| `AlertTitle`       | Bold heading text                  |
| `AlertDescription` | Supporting description text        |
