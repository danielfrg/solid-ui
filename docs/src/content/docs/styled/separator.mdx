# Separator

## Usage

Add the theme to your CSS:

```css
@import "tailwindcss";
@import "@danielfrg/ui/theme.css";
```

Import and use the `Separator` component:

```tsx
import { Separator } from "@danielfrg/ui/separator";

<Separator />
<Separator orientation="vertical" />
```
