# Badge

## Usage

Add the theme to your CSS:

```css
@import "tailwindcss";
@import "@danielfrg/ui/theme.css";
```

Import and use the `Badge` component:

```tsx
import { Badge } from "@danielfrg/ui/badge"

<Badge variant="outline">Badge</Badge>
```

## Variants

| Variant       | Description                    |
| ------------- | ------------------------------ |
| `default`     | Primary background             |
| `secondary`   | Muted background               |
| `outline`     | Bordered with transparent fill |
| `destructive` | Red destructive styling        |
| `ghost`       | No background                  |
| `link`        | Text link appearance           |
