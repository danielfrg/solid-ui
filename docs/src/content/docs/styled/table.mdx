# Table

## Usage

Add the theme to your CSS:

```css
@import "tailwindcss";
@import "@danielfrg/ui/theme.css";
```

Import and use the `Table` components:

```tsx
import { Table, TableHeader, TableBody, TableRow, TableHead, TableCell, TableCaption } from "@danielfrg/ui/table"

<Table>
  <TableCaption>A list of recent invoices.</TableCaption>
  <TableHeader>
    <TableRow>
      <TableHead>Invoice</TableHead>
      <TableHead class="text-right">Amount</TableHead>
    </TableRow>
  </TableHeader>
  <TableBody>
    <TableRow>
      <TableCell>INV001</TableCell>
      <TableCell class="text-right">$250.00</TableCell>
    </TableRow>
  </TableBody>
</Table>
```

## Parts

| Component      | Description                             |
| -------------- | --------------------------------------- |
| `Table`        | Root table with overflow scroll wrapper |
| `TableHeader`  | `<thead>` with bottom border on rows    |
| `TableBody`    | `<tbody>` with no border on last row    |
| `TableFooter`  | `<tfoot>` with muted background         |
| `TableRow`     | `<tr>` with hover and selected states   |
| `TableHead`    | `<th>` header cell                      |
| `TableCell`    | `<td>` body cell                        |
| `TableCaption` | `<caption>` muted text below table      |
