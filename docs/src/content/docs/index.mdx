# danielfrg/solid-ui

A collection of unstyled and styled SolidJS components.

- Headless primitives from `@danielfrg/solid-ui-core`: most forked from [Kobalte](https://kobalte.dev) and others adapted from [Base UI](https://base-ui.com/)
- Styled components from `@danielfrg/solid-ui`: Use the headless components and adapted the [shadcn](https://ui.shadcn.com/) based on the Nova theme.

# Quick start

Install the styled components:

```bash
npm install @danielfrg/solid-ui
```

Add the theme to your CSS:

```css
@import "tailwindcss";
@import "@danielfrg/solid-ui/theme.css";
```

Import and use:

```tsx
import { Button } from "@danielfrg/solid-ui/button"
<Button variant="outline">Click me</Button>
```

For headless/unstyled primitives only:

```bash
npm install @danielfrg/solid-ui-core
```

```tsx
import { Button } from "@danielfrg/solid-ui-core/button"
```
