# danielfrg/solid-ui

Unstyled UI components for SolidJS.

Mostly forked from [Kobalte](https://kobalte.dev) and others adapted from [Base UI](https://base-ui.com/).

Also provide an implementation of [shadcn style components](/nova) (with variants and so on) based on their Nova styles in `@danielfrg/solid-ui-nova`

If you want your own components you can fork the styled package and customize them.
It's very easy to create your own styles with LLMs by forking the nova example theme.

# Quick start

Install:

```bash
npm install @danielfrg/solid-ui
```

Import the components you need:

```tsx
import { Button } from "@danielfrg/solid-ui/button"
```

Use and style the components in your app:
